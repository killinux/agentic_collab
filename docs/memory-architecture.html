🧠 记忆系统架构

基于斯坦福 Generative Agents 论文

总体数据流

感知(perceive) → 新事件存入联想记忆
↓
检索(retrieve) → 三维加权找最相关的 30 条记忆
↓
规划(plan) → 基于检索结果制定日程
↓
反思(reflect) → 重要性累积触发，产生高层想法
↓
执行(execute) → 角色移动、互动
↓
对话(converse) → 基于记忆和情境生成对话

三层记忆结构

1. 联想记忆（长期记忆）

memory_structures/associative_memory.py

每条记忆是一个 ConceptNode，有三种类型：

event 事件 thought 想法 chat 对话

节点字段

字段说明
node_id唯一标识，如 "node_1"
typeevent / thought / chat
subject / predicate / object三元组，如 "Isabella - 正在准备 - 派对"
description完整文字描述
poignancy重要性 1-10（LLM 打分）
embedding_key用于生成 1536 维嵌入向量的文本
keywords关键词集合，用于快速索引
filling证据链（想法→原始记忆）
created / last_accessed创建时间 / 最后检索时间

索引结构

结构用途
seq_event / seq_thought / seq_chat按时间排序的列表
kw_to_event / kw_to_thought关键词 → 记忆索引
kw_strength_event关键词频次（触发反思）
embeddings文本 → 1536 维向量缓存

2. 工作记忆（短期记忆）

memory_structures/scratch.py

身份信息

name, age, innate（天生特质）, learned（习得特质）, currently（当前状态）, lifestyle（作息）

感知参数

参数默认值含义
vision_r4视野半径（格）
att_bandwidth3每步最多感知事件数
retention5不重复感知的窗口

反思控制

参数值含义
importance_trigger_max150计数器最大值
importance_trigger_curr递减减到 0 触发反思
recency_decay0.99时近性衰减率

当前状态

日程(daily_req)、当前行动(act_description)、对话状态(chatting_with, chat)

3. 空间记忆

memory_structures/spatial_memory.py

层级树结构，角色只记住去过/看到过的地方：

世界（the Ville）
  └─ 区域（Hobbs Cafe）
       └─ 房间（cafe）
            └─ 物品（counter, table, coffee machine）

核心算法

记忆检索

cognitive_modules/retrieve.py

对每条记忆打三个分，加权求和后取 top-30：

维度计算方法权重
时近性 Recency0.99 ^ 位置序号×0.5
相关性 Relevance余弦相似度×3（最重要）
重要性 Importancepoignancy 分数×2
公式： score = recency×0.5 + relevance×3.0 + importance×2.0
语义匹配是第一优先级，其次是重要事件，最后是时间远近。

感知流程

cognitive_modules/perceive.py

Step 1：获取视野内事件

扫描 vision_r=4 格范围内的 tile，按距离排序取最近 3 个

Step 2：新颖性检查

跳过最近 retention=5 条内已感知的事件

Step 3：存储

生成嵌入向量 → LLM 打重要性分 → 存入联想记忆 → 递减反思计数器

反思流程

cognitive_modules/reflect.py

触发条件

importance_trigger_curr ≤ 0（感知事件的重要性累积到阈值）

Step 1：生成焦点问题

LLM 从最近高重要性记忆中提取 3 个值得思考的主题

Step 2：检索相关记忆

对每个焦点问题用三维检索找 top-30 记忆

Step 3：生成洞察

LLM 基于检索的记忆产生新想法，存为 thought 节点

Step 4：链接证据

新想法的 filling 字段指向产生它的原始记忆

Step 5：重置计数器

importance_trigger_curr = 150，等待下一轮

涌现行为的产生

关键机制：

1. 每个角色独立运行完整的认知循环

2. 角色之间唯一的信息交换：同一空间感知 + 对话

3. 记忆检索 + 反思让角色能联系不同事件产生洞察

4. 多角色各自独立做出一致决策 → 涌现行为

例子：Isabella 分别告诉 Klaus 和 Maria "下午 1 点在 Hobbs Cafe"。两人各自存入记忆，规划日程时检索到它，于是三人都出现在同一时间同一地点——没有中央调度，完全自发协调。

文件磁盘格式

存储目录结构

storage/<sim_name>/personas/<Name>/bootstrap_memory/
├── scratch.json              # 工作记忆（JSON 对象）
├── spatial_memory.json       # 空间记忆（嵌套 JSON 树）
└── associative_memory/
    ├── nodes.json            # 所有记忆节点（JSON 对象）
    ├── embeddings.json       # 文本→向量映射（JSON 对象）
    └── kw_strength.json      # 关键词频次（JSON 对象）

nodes.json 示例

{
  "node_5": {
    "node_count": 5,
    "type": "thought",
    "depth": 1,
    "created": "2023-02-13 00:00:00",
    "subject": "Isabella Rodriguez",
    "predicate": "plan",
    "object": "Valentine's Day party",
    "description": "应该邀请 Klaus 来派对讨论社区话题",
    "poignancy": 7,
    "keywords": ["plan", "party"],
    "filling": ["node_1", "node_3"]
  }
}

embeddings.json 示例

{
  "Isabella is preparing for the party": [0.012, -0.034, 0.056, ...]
}
// 每个值是 1536 维浮点数组
