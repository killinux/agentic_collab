记忆系统实战

以 7 人中文仿真 zh-n7-day1 中 Tom Moreno 的真实数据为例

文件总览

personas/Tom Moreno/bootstrap_memory/
├── scratch.json            ← 工作记忆
├── spatial_memory.json     ← 空间记忆
└── associative_memory/
    ├── nodes.json          ← 长期记忆（413条）
    ├── embeddings.json     ← 语义向量（176条）
    └── kw_strength.json    ← 关键词计数

数据流

感知 → nodes.json + embeddings.json（存新记忆）
↓ kw_strength.json（关键词+1）
↓ scratch.json（重要性计数递减）
↓ 递减到 0 时
反思 → embeddings.json（语义检索）→ nodes.json（存新想法）
↓
规划 → scratch.json（更新日程）
↓
对话 → nodes.json（存对话记录）

Tom 知道的地方——只有去过或看到过的才会记住（共 11 个区域）：

{
  "the Ville": {
    "Moreno family's house": {
      "common room": [...],
      "Tom and Jane Moreno's bedroom": [...]
    },
    "The Willows Market and Pharmacy": { "store": [...] },

    },

三、nodes.json — 长期记忆

Tom 的全部记忆，413 条，分三种类型： event 事件 357条 thought 想法 52条 chat 对话 4条

event 事件 — 感知到的事实

{
  "node_count": 413,
  "type": "event",
  "subject": "Tom Moreno",
  "predicate": "discuss",
  "object": "项目预算细节",
  "description": "Tom Moreno is 正在与 Klaus 讨论项目预算细节",
  "poignancy": 5,
  "keywords": ["Tom Moreno", "项目预算细节"],
  "embedding_key": "Tom Moreno is 正在与 Klaus 讨论项目预算细节",
  "filling": []
}
字段说明
poignancy = 5LLM 打的重要性分（1-10），中等偏高
embedding_key这段文字会被转成 2048 维向量
filling = []事件是第一手事实，没有证据链

thought 想法 — 反思产生的认知

{
  "node_count": 384,
  "type": "thought",
  "depth": 1,
  "description": "Tom Moreno was interested in Abigail Chen's
    ideas about integrating digital art and animation
    into the Oak Hill College project",
  "poignancy": 4,
  "filling": ["node_363"]
}
证据链：filling = ["node_363"] → 这条想法来源于 node_363（和 Abigail 的对话）。想法不是凭空产生的，可以追溯到原始事件。

chat 对话 — 完整对话记录

{
  "node_count": 363,
  "type": "chat",
  "subject": "Tom Moreno",
  "predicate": "chat with",
  "object": "Abigail Chen",
  "description": "talking to Abigail Chen and Isabella about
    the Oak Hill College project...",
  "filling": [
    ["Tom Moreno", "Abigail，你好！真高兴在这里见到你..."],
    ["Abigail Chen", "你好，Tom！是的，我正好是来参加..."],
    ...14轮完整对话...
  ]
}

chat 节点的 filling 不是证据链，而是完整对话原文。

四、embeddings.json — 语义向量

{
  "Tom Moreno is 正在与 Klaus 讨论项目预算细节":
    [0.012, -0.034, 0.056, ...2048个浮点数],
  "Tom Moreno is 正在准备联系 Klaus 的材料":
    [-0.008, 0.021, 0.044, ...],
  ...176条...
}

检索时怎么用

1
把当前情境 "Abigail Chen 走进 Hobbs Cafe" 转成 2048 维向量
2
和 Tom 的 176 条向量逐一算余弦相似度
3
"之前和 Isabella 讨论过 Oak Hill College 项目" 这条语义最接近
4
Tom "想起"了这件事 → 对话时主动提到了项目
检索公式：score = 时近性×0.5 + 相关性×3.0 + 重要性×2.0
相关性（余弦相似度）权重最高——语义匹配优先。

五、kw_strength.json — 关键词频次

{
  "kw_strength_event": {
    "tom moreno": 63,
    "cafe customer seating": 25,
    "john lin": 21,
    "abigail chen": 19,
    "isabella rodriguez": 19
  },
  "kw_strength_thought": {
    "tom moreno": 51,
    "have": 9,
    "work": 8,
    "prepare": 7,
    "meet": 7
  }
}

关键词计数超过阈值（默认 4）时，该主题被标记为"值得反思"。Tom 和 "isabella rodriguez"、"abigail chen" 相关的事件各 19 次——这些高频主题会被优先选为反思焦点。

六、完整示例：Tom ↔ Abigail 对话全链路

阶段 1：碰面前

spatial_memory.json Tom 知道 Hobbs Cafe 的位置

scratch.json 日程里有 "上午 10 点在 Hobbs Cafe 与 Isabella 会面"

plan 模块读取日程，驱动 Tom 走向 Hobbs Cafe

阶段 2：感知 Abigail

Tom 到达 Hobbs Cafe，视野内出现 Abigail Chen：

1
扫描 vision_r=4 格内的 tile
2
检测到 "Abigail Chen 在 cafe customer seating"
3
调 embedding API 生成向量 → 存入 embeddings.json
4
调 LLM 打重要性分 → poignancy=4 → 存入 nodes.json
5
更新 kw_strength.json：abigail chen: 18 → 19
6
更新 scratch.json：importance_trigger_curr -= 4

阶段 3：决定是否交谈

1
用 "Abigail Chen 在 Hobbs Cafe" 查询 embeddings.json
2
找到语义最相关的记忆："Isabella 提到过 Abigail 参与 Oak Hill College 项目"
3
LLM 判断：是，应该和 Abigail 聊聊项目

阶段 4：对话（14 轮）

Tom Moreno
Abigail，你好！真高兴在这里见到你。我正在和 Isabella 讨论 Oak Hill College 项目，你也是来参加这个项目的吗？
Abigail Chen
你好，Tom！是的，我正好是来参加 Oak Hill College 项目的。你们已经开始讨论可能的解决方案了吗？
Tom Moreno
是的，Isabella 正在整理项目预算的细节，而我准备了设备采购和人员培训的草案。你有什么特别关注的领域吗？
Abigail Chen
我对创意表达和技术实现特别感兴趣，尤其是数字艺术和动画方面的应用...

...共 14 轮，最终约定明天下午 3 点在 Hobbs Cafe 再开会

阶段 5：对话存储

1
14 轮完整对话存入 nodes.json（chat 节点 node_363）
2
对话摘要的向量存入 embeddings.json
3
kw_strength.json 中 "abigail chen" 计数 +1
4
scratch.json 的 importance_trigger_curr 继续递减

阶段 6：反思

当 importance_trigger_curr ≤ 0 时触发：

1
kw_strength.json 发现 "abigail chen"、"oak hill college" 频繁出现
2
用 embeddings.json 检索相关记忆
3
LLM 生成想法："Tom 对 Abigail 将数字艺术融入项目的想法很感兴趣"
4
新 thought 存入 nodes.json（node_384），filling → node_363
5
重置 scratch.json：importance_trigger_curr = 150

阶段 7：影响未来行为

下次 Tom 做日程规划时，plan 模块检索到 node_383：

"明天下午 3 点在 Hobbs Cafe 与 Isabella 和 Abigail 讨论预算"

这条记忆被写入新的日程 → Tom 明天真的会去赴约。

整个链路：感知 → 记忆 → 检索 → 对话 → 存储 → 反思 → 影响未来规划。没有中央调度，每个角色独立运行这个循环。

七、核心概念

涌现行为（Emergent Behavior）

没有代码告诉 Tom "你应该和 Abigail 讨论数字艺术"。这个行为来自独立决策的叠加：

• Isabella 独立决定筹办 Oak Hill College 项目
• Tom 独立规划了去 Hobbs Cafe 开会
• Abigail 独立决定去 Hobbs Cafe 讨论项目
• 三人碰巧在同一地点相遇 → 对话自然发生

重要性评分（Poignancy）

分数实际例子
1bed is idle（家具状态）
3正在准备联系 Klaus 的材料
5正在与 Klaus 讨论项目预算细节
6和 Abigail 的完整对话记录

两个用途：检索排序权重 + 累积触发反思

证据链（Filling / Evidence）

node_384 (thought): "Tom 对 Abigail 的数字艺术想法感兴趣"
  └─ filling → node_363 (chat): Tom ↔ Abigail 的 14 轮对话

每条想法都有证据，可以追溯"为什么角色会这样想"。

注意力带宽 & 记忆保留

参数值含义
att_bandwidth3每步最多感知 3 个事件（模拟注意力有限性）
retention5最近 5 步内已感知的事件不重复存储

文件关系图

scratch.json ←→ plan (日程) / execute (行动) / perceive (触发器递减)

spatial_memory.json ←→ plan (可选目的地) / perceive (发现新地点)

nodes.json ← perceive (event) / reflect (thought) / converse (chat)
           → retrieve (被检索) / plan+converse (作为 LLM 输入)

embeddings.json ← perceive/reflect/converse (生成向量)
                → retrieve (余弦相似度检索)

kw_strength.json ← perceive (event关键词+1) / reflect (thought关键词+1)
                 → reflect (判断哪些主题值得反思)
